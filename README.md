# CDN Edge & Anycast Latency Checker

Асинхронный инструмент на чистом Python (`asyncio`) для мгновенного замера TCP-пинга (порт 443 HTTPS) до публичных Anycast и Edge IP-адресов крупнейших CDN-провайдеров:

- **Gcore CDN** (официальные edge-ноды + anycast)
- **Cloudflare** (официальные диапазоны + Anycast)
- **AWS CloudFront** (Global Edge + Regional)
- **Fastly**
- **QUIC.cloud**
- **ArvanCloud**
- **CacheFly** (AS30081)

## Особенности
- Не требует прав `root` (работает в Termux на Android, Linux, macOS, Windows).
- Чистая стандартная библиотека Python (без сторонних `pip` зависимостей).
- Автономен: не резолвит домены и не ходит на внешние API в процессе работы (подходит для работы в изолированных сетях и белых списках).
- Проверяет ~2500 IP-адресов за 2–4 секунды.

## Использование в Termux / Linux

1. Клонируйте или перейдите в папку:
```bash
cd cdn-checker
```

2. Запустите скрипт:
```bash
python3 ping_cdn.py
```

## Выходные данные
- В консоль выводится краткая сводка со статистикой ответивших IP по каждой компании.
- В файл `alive_cdn_ips.json` сохраняются все ответившие IP-адреса с задержкой в миллисекундах (`latency_ms`), отсортированные от самых быстрых к медленным.
