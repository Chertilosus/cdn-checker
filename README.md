# Gcore CDN Edge & Anycast Latency Checker

Асинхронный инструмент на чистом Python (`asyncio`) для мгновенного замера TCP-пинга (порт 443 HTTPS) до всех Anycast и Edge IP-адресов сети **Gcore CDN**.

## Особенности
- **Только Gcore**: проверяет глобальные Anycast-адреса, официальные edge-серверы и развёрнутые хосты официальных публичных подсетей Gcore (~5900 IP-адресов).
- **Без внешних запросов во время работы**: все адреса уже вшиты в `cdn_ips.json` (работает в изолированных сетях и при тестировании белых списков).
- **Быстро**: асинхронный событийный цикл проверяет всю сеть в 250 одновременных потоков за 3–5 секунд.
- **Работает без root**: чистый TCP-замер на порт 443 (стандартная библиотека Python, без `pip`).

## Использование в Termux / Linux

1. Скачать и перейти в папку:
```bash
pkg install -y git python && git clone https://github.com/Chertilosus/cdn-checker.git && cd cdn-checker
```

2. Запустить проверку:
```bash
python3 ping_cdn.py
```

## Результаты
- В консоль выводится краткая сводка (общее количество ответивших) и топ-15 самых быстрых IP с миллисекундами.
- Все живые IP, отсортированные по задержке, сохраняются в файл `alive_gcore_ips.json`.
